# 🌐 浏览器服务

让 AstrBot 浏览真实网页，也为其他插件提供共享的截图和 PDF 渲染服务。

`astrbot_plugin_browser` 提供 **23 个 BrowserUse 模型工具**，覆盖网页阅读、鼠标与表单操作、文件上传下载、登录状态保存和高级控制；同时提供 **HTML → PNG / PDF** 接口，让 Markdown 渲染、网页卡片和报告导出等插件共用浏览器。

[功能亮点](#features) · [快速开始](#quick-start) · [能力概览](#capabilities) · [常用配置](#configuration) · [技术原理与配置](./docs/技术原理与配置.md) · [开发接入](./docs/技术原理与配置.md#integration)

## 🌟 功能亮点

### 🤖 BrowserUse 网页操作

通过自然语言提出任务，模型根据页面观察连续完成浏览操作。

| 能力 | 可以做什么 |
| --- | --- |
| 网页阅读与观察 | 打开网页、读取页面文字和交互元素，查看页面截图 |
| 鼠标与表单 | 点击、双击、右键、悬停、拖拽、输入、按键、选择与滚动 |
| 多轮操作 | 保留个人浏览会话，在多个标签页间继续任务 |
| 文件与内容 | 上传消息附件、下载并发送文件，提取表格、链接、列表和正文 |
| 登录与人工接手 | 会话结束时保存登录状态；明确请求时打开有头窗口，方便人工登录和操作 |
| 高级控制 | 网络监听、请求拦截、设备环境模拟与页面 JavaScript 执行 |

### 🧩 共享渲染服务

为其他 AstrBot 插件提供统一的浏览器接口，减少各插件重复启动 Chromium 的资源开销。

| 能力 | 可以做什么 |
| --- | --- |
| HTML 渲染 | 将 HTML 渲染为 PNG，支持整页、当前视口和指定元素截图 |
| PDF 导出 | 设置纸张、方向、边距与打印背景，生成 PDF 文件内容 |
| 自定义页面操作 | 获取临时页面，自行测量内容、分页或控制截图细节 |
| 资源管理 | 共用执行并发与排队限制，可选空闲关闭，下次调用自动启动 |

默认使用无头浏览器，不显示窗口。联网浏览会话与离线渲染任务分别隔离，渲染完成后释放临时页面。[其他插件接入参考](./docs/技术原理与配置.md#integration)

## ✨ 为什么需要它

### 一个浏览器，多个插件共享

浏览器是比较占资源的组件。如果 Markdown 渲染、网页卡片、报告导出等插件各自启动一套 Chromium，很快就会出现多个浏览器进程、重复的 Playwright 驱动和重复的缓存。

默认只维护一个共享的无头 Chromium 实例；额外的有头实例仅在明确请求后存在：

```text
AstrBot
  ├─ Markdown 渲染插件 ─┐
  ├─ 报告导出插件      ─┼─> 共享 Browser(Chromium) ─> 独立 BrowserContext
  └─ 网页卡片插件      ─┘
```

这样可以减少重复的浏览器进程和基础开销，通常比每个插件各自启动浏览器更省内存。`browser.max_concurrent_sessions` 还可以限制同时运行的页面任务数量，避免并发渲染把内存一次性推高。

共享不等于没有成本：Chromium 本身仍然需要内存，每个并发页面也会占用额外资源。插件通过任务排队、超时和像素上限把这笔开销控制在可预期范围内。

#### 浏览器内存结构示例

```bash
Chromium（浏览器实例）									# 150～300 MB
└── BrowserContext（独立会话：Cookie、登录状态、缓存等）  # 10～60 MB
    ├── Page（标签页）								 # 10～80 MB
    └── Page（标签页）								 # 10～80 MB
```

### 会话与渲染任务相互隔离

每个 Agent 使用者及每个离线渲染任务使用独立的 BrowserContext。不同上下文之间不共享 Cookie、Local Storage 和页面状态；同一 Agent 会话内部保留状态，便于连续操作。

### HTML 截图和 PDF 一套接口

- HTML 渲染为 PNG 字节，可直接交给 `Image.fromBytes()`。
- HTML 渲染为 PDF 字节，可直接保存或交给文件消息组件。
- 支持完整 CSS、字体等待、元素选择器截图和整页截图。

### 离线渲染接口

- 浏览器使用无头模式运行。
- `render_html()`、`render_pdf()` 和 `session()` 默认禁用 JavaScript。
- 这些渲染接口的页面请求全部拦截，不访问外部网站、外部图片或本地文件。
- Agent 工具使用独立的联网会话，不改变渲染接口的离线约定。

如果业务确实需要脚本，可以只对单个 `session()` 调用设置 `javascript_enabled=True`。这不会改变其他任务的默认设置。

## ⚡ 快速开始

### 1. 准备环境

| 项目 | 要求 |
| --- | --- |
| AstrBot | `>=4.27,<5` |
| Python 依赖 | `playwright>=1.58,<2`，安装在运行 AstrBot 的同一环境中 |
| 浏览器 | Playwright Chromium 或本机 Chromium 系浏览器，缺失时会自动下载 |
| 模型 | 使用 BrowserUse 时需要支持工具调用；截图观察还需要支持图片输入 |
| 图形桌面 | 仅有头模式需要，桌面位于 AstrBot 所在主机 |

只使用渲染服务时，可以关闭 BrowserUse，无需配置模型工具。

### 2. 安装插件

从插件市场安装本插件，或者在 AstrBot WebUI 的插件管理中，使用以下仓库地址安装：

```text
https://github.com/rytte/astrbot_plugin_browser
```

也可以将完整仓库目录放入 `AstrBot/data/plugins/astrbot_plugin_browser/`，在运行 AstrBot 的 Python 环境中安装依赖，再重载插件：

```bash
python -m pip install -r data/plugins/astrbot_plugin_browser/requirements.txt
```

插件加载时会自动按以下顺序准备 Chromium：

1. 使用 Playwright 已安装的 Chromium。
2. 查找本机可用的 Chromium、Chrome、Edge、Brave、Vivaldi 或 Opera。
3. 如果仍未找到，自动执行 `python -m playwright install chromium`。

因此通常不需要手动执行浏览器安装命令。自动下载需要网络和当前 Python 环境的写入权限。

> [!TIP]
>
> Linux 如果自动下载后仍缺少浏览器系统依赖，可以手动安装：
>
> ```bash
> python -m playwright install --with-deps chromium
> ```

### 3. 启用浏览工具

在插件配置的 **BrowserUse** 组中，保留“启用 BrowserUse 模型工具”，选择所需的“模型工具层级”，然后在 AstrBot 工具管理中为目标人格启用相应的 `browser_*` 工具。

默认使用“基础浏览”，适合先体验阅读、搜索和表单操作。需要上传下载等能力时，再选择“完整交互”或“高级控制”。

**默认仅 AstrBot 管理员可用。** 其他用户需加入 **BrowserUse 白名单**，逐项填写个人用户 ID（如 QQ 号）。保存配置后重载插件生效。

### 4. 试着说一句

按当前会话的唤醒方式与机器人对话，例如在群聊中先 @ 机器人，再提出请求。通常无需手写工具名和参数。

| 场景 | 示例请求 | 工具层级 |
| --- | --- | --- |
| 阅读网页 | “打开 https://example.com，概括页面内容。” | 基础浏览 |
| 搜索与整理 | “打开我提供的商品网站，搜索无线键盘，按价格排序，整理前三项结果。” | 基础浏览 |
| 上传附件 | “把这条消息附带的文件上传到网页的附件栏。” | 完整交互 |
| 下载文件 | “下载这份报告，完成后把文件发到当前聊天。” | 完整交互 |
| 人工登录 | “打开有头浏览器，我来手动登录。” | 基础浏览，需图形桌面 |

截图用于模型观察页面，不会自动作为图片消息发送到聊天中。上传下载还取决于当前平台的附件与文件消息支持。

<a id="capabilities"></a>

## 🧬 能力概览

### 工具层级

高层包含低层的全部工具，未启用的工具定义不占模型上下文。

| 配置值 | WebUI 选项 | 工具数量 | 适用范围 |
| --- | --- | ---: | --- |
| `basic`（默认） | 基础浏览 | 13 | 网页观察、截图、点击与表单、标签页、等待、模式切换 |
| `standard` | 完整交互 | 19 | 增加拖拽、上传下载、结构化提取、弹窗和登录状态管理 |
| `full` | 高级控制 | 23 | 增加网络监听、请求拦截、设备模拟和 JavaScript 执行 |

登录状态的自动保存与恢复在三个层级均可用。完整工具清单与参数见 [BrowserUse 工具](./docs/技术原理与配置.md#tools)。

### 谁可以使用

管理员与白名单用户拥有相同的浏览器工具权限，可以在**私聊和任意群聊**中使用；群里其他人不会因此获得权限。所有人仍受全局工具层级、有头模式开关和工具启停设置限制。

不同聊天来源和发送者的页面、文件与登录快照分别隔离。同一个人在不同聊天中的会话也相互独立。授权只匹配发送者 ID，多平台使用时，相同发送者 ID 会命中同一白名单条目。

BrowserUse 使用 AstrBot 所在主机的网络和网站登录状态，请仅向可信用户授权。供其他插件调用的离线渲染接口不受个人白名单限制。详见 [权限与会话隔离](./docs/技术原理与配置.md#permissions)。

### 有头浏览与登录保存

默认浏览在后台运行。明确请求有头模式时，窗口显示在 **AstrBot 所在主机**，最多一个有头实例和一个有头会话；会话结束后释放。

正常结束会话、通过工具关闭最后一个标签页、空闲回收或正常停止插件时，会尝试保存登录状态，下次创建同一身份的会话时自动恢复。浏览期间不会每次操作都写盘。浏览器崩溃或强制结束进程时，无法保证保存最新状态。

有头与无头之间切换会保留登录存储并重建页面，需要重新打开网址。详细行为见 [有头模式与人工操作](./docs/技术原理与配置.md#headed) 和 [登录状态与文件](./docs/技术原理与配置.md#storage)。

### 其他插件如何接入

通过 AstrBot 的插件上下文获取已注册的 `service`，再调用以下接口：

| 接口 | 返回或提供的内容 |
| --- | --- |
| `render_html()` | PNG 图片字节，可交给 AstrBot 的图片消息组件 |
| `render_pdf()` | PDF 字节，可保存或交给文件消息组件 |
| `session()` | 自动清理的临时页面，供调用方自定义操作 |

渲染接口拦截页面的外部资源请求，HTML 中的 CSS、图片和字体应内联。开启空闲关闭后，这些接口会自动唤醒浏览器，已有接入方式保持兼容。

完整示例和参数见 [其他插件接入](./docs/技术原理与配置.md#integration)。

## ⚙️ 常用配置

配置在 AstrBot WebUI 中调整，保存后重载插件生效。

| 配置位置 | 默认值 | 作用 |
| --- | --- | --- |
| BrowserUse → 启用 BrowserUse 模型工具 | 开启 | 关闭后仅保留供其他插件调用的渲染服务 |
| BrowserUse → BrowserUse 白名单 | 空列表 | 空列表仅管理员可用；填写个人用户 ID 后向这些用户开放 |
| BrowserUse → 模型工具层级 | 基础浏览（13 个工具） | 选择基础浏览、完整交互或高级控制 |
| BrowserUse → 允许按需使用有头浏览器 | 开启 | 允许明确请求时启动窗口，需要主机有图形桌面 |
| BrowserUse → Agent 会话空闲回收时间 | 600 秒 | 个人会话空闲到期后，保存登录状态并关闭页面 |
| 浏览器基础设置 → 最大并发页面任务数 | 4 | BrowserUse 操作和离线渲染共享的执行名额 |
| 浏览器基础设置 → 空闲时关闭浏览器 | 关闭 | 无头实例空闲时释放，下次浏览或渲染自动启动 |
| 浏览器基础设置 → 浏览器实例空闲超时 | 1200 秒（20 分钟） | 开启空闲关闭后显示，可自行调整 |

**会话回收与实例关闭分别计时。** 只有没有保留的无头会话、执行中或排队的无头任务时，才开始实例空闲计时。例如会话回收设为 600 秒、实例超时设为 1200 秒，最后一次操作后约 1800 秒释放无头实例。

完整字段、范围、旧版配置说明与资源生命周期见 [技术原理与配置](./docs/技术原理与配置.md#configuration)。

## 🧯 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 提示没有权限 | 确认发送者是 AstrBot 管理员，或已将其个人 ID 加入 BrowserUse 白名单并重载插件 |
| 模型没有使用浏览工具 | 检查模型的工具调用能力、BrowserUse 开关、目标人格工具启用情况与所选工具层级 |
| 没有浏览器窗口 | 默认是无头模式；只有明确请求有头模式且主机有可用图形桌面时才显示窗口 |
| 模型无法查看截图 | 使用支持图片输入的模型，并在 AstrBot 提供商配置中启用 `image` 能力 |
| 渲染缺少图片或字体 | 离线渲染不加载外部资源，请将资源内联到 HTML 中 |

浏览器安装、超时排队和登录恢复的处理方式见 [故障排查](./docs/技术原理与配置.md#faq)。
