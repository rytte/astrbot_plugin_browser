# 共享浏览器：配置与插件接入

共享浏览器为其他 AstrBot 插件提供离线 HTML 截图、PDF 和受限页面操作。本文说明共用 Chromium 的配置、生命周期、公开 API 与开发验证。模型网页工具的权限、个人会话及登录状态见[BrowserUse](./BrowserUse.md)，安装步骤见[项目首页](../README.md)。

## 💠 配置参考

**浏览器基础设置**（`browser`）由 BrowserUse 和离线渲染共用：

| 配置项 | 默认值 | 范围 | 说明 |
|---|---:|---:|---|
| `browser.browser_executable` | 空 | 绝对路径 | 留空自动选择 Playwright Chromium 或本机 Chromium 系浏览器；也可以填写已有浏览器的绝对路径，不要加引号 |
| `browser.max_concurrent_sessions` | `4` | 1～16 | 离线渲染与 BrowserUse 操作共享的执行并发；空闲会话不占执行名额 |
| `browser.queue_timeout` | `30` 秒 | 1～300 | 任务排队超时；执行名额满时等待的最长时间 |
| `browser.startup_timeout` | `30` 秒 | 1～120 | 启动共用 Chromium 的最长时间 |
| `browser.idle_shutdown_enabled` | `false` | 布尔值 | 无头实例空闲时关闭，下次浏览或渲染请求自动启动 |
| `browser.idle_shutdown_timeout` | `1200` 秒 | 30～86400 | 开启空闲关闭后显示；无头实例无任务和保留 Context 后的等待时间 |

**共享渲染服务**（`render`）控制供其他插件调用的接口：

| 配置项 | 默认值 | 范围 | 说明 |
|---|---:|---:|---|
| `render.enabled` | `true` | 布尔值 | 是否启用共享 HTML 截图、PDF 和临时页面接口；关闭不影响 BrowserUse |

保存配置后重载插件生效。关闭共享渲染后，公开的 `service.ready` 返回 `False`，`render_html()`、`render_pdf()` 和 `session()` 均抛出 `BrowserServiceError`，提示共享渲染服务已关闭。BrowserUse 可单独关闭，不影响渲染开关；专用配置见[BrowserUse 配置](./BrowserUse.md#configuration)。

两个功能都关闭时，不初始化浏览器，也不触发 Chromium 自动安装；已下载的浏览器文件保留。仅关闭共享渲染时，BrowserUse 仍使用共用 Chromium，实例的空闲释放继续由 `browser.idle_shutdown_enabled` 控制。

### 旧版配置

原顶层浏览器路径、并发、排队和启动超时配置已移入 `browser` 组；原顶层 `max_agent_sessions`、`agent_idle_timeout`、`agent_action_timeout` 已移入 `browser_use` 组并更名。手动配置请使用表中的新路径，不提供旧字段别名；若将旧字段直接传入插件，会报未知配置错误。AstrBot 配置加载器可能按新 schema 清理旧字段并补入默认值，升级前请记录旧值，再在新组中重新设置。

## 🧩 浏览器运行与生命周期

### 实例与上下文

`BrowserService` 管理一个共享无头 Chromium、一个按需启动的有头 Chromium，以及共享的 Playwright 驱动。BrowserUse 和离线渲染复用无头实例，明确请求有头模式时才额外启动窗口。

普通模式中每个 Agent 身份和每个离线渲染任务使用独立的 `BrowserContext`，不同上下文不共享 Cookie、Local Storage 和页面状态。Agent Context 跨多轮保留；渲染 Context 在 `session()` 退出时关闭。

普通模式使用 Context 配合 `storage_state` 快照保存登录状态，不使用 persistent context 或共享浏览器用户目录。有头模式由插件创建独立实例。可选的 [CDP 模式](./BrowserUse.md#cdp)在明确请求时自动发现并经 Chrome 授权连接正在使用的普通浏览器；通过独立连接操作已有浏览器，不交给 `BrowserService` 管理其进程，不载入或导出插件登录快照，也不用于离线渲染；仅共用任务执行名额。

### 执行并发

`browser.max_concurrent_sessions` 限制同时执行的页面任务。BrowserUse 无头/有头/CDP 操作与离线渲染共用这些名额；人工等待和保留但未操作的会话不占执行名额。满额后最多排队 `browser.queue_timeout` 秒。BrowserUse 另行限制保留的会话数，见[个人会话生命周期](./BrowserUse.md#lifecycle)。

### 无头实例空闲关闭

默认 `browser.idle_shutdown_enabled=false`，无头实例保持运行。开启后，WebUI 展示 `browser.idle_shutdown_timeout`，默认 1200 秒，允许 30～86400 秒。

以下条件全部满足时才计算实例空闲时间：

- 没有执行中或排队的无头任务，包含 BrowserUse、HTML/PDF 渲染和底层 `session()`。
- 没有保留的无头 Context；仍保留页面的 Agent 会话会阻止关闭。
- 服务未在停止，且实例空闲已达到设定时间。

任务完成和 Context 关闭都会刷新计时。后台最多每 30 秒检查一次，因此实际关闭可能延后约 30 秒。Agent 会话超时和实例超时先后生效：会话 600 秒、实例 1200 秒时，最后一次操作后约 1800 秒释放无头实例。

休眠只关闭无头 Browser，保留共享 Playwright 驱动，不影响仍在使用的有头实例。`service.ready` 在休眠时仍返回可用；下次浏览或渲染请求自动启动实例，并发请求共用同一次启动。关闭与新请求通过同一生命周期锁协调，已经开始关闭时到来的请求等待完成后再唤醒。

PNG/PDF 渲染和 BrowserUse 的整体超时包含启动等待。底层 `session()` 的 `timeout` 设置单次 Playwright 操作时限，排队与浏览器启动另受服务配置限制。

### 插件停止

正常停止时先取消未完成调用、完成 BrowserUse 的会话保存，再释放页面、两个浏览器实例、Playwright 驱动及回收任务。临时文件被清理，登录快照保留；具体保存行为见[登录状态与文件](./BrowserUse.md#storage)。

## 🔌 其他插件接入

其他插件通过 AstrBot 的插件上下文获取已注册的浏览器服务：

```python
from astrbot.api.star import Star


class ExamplePlugin(Star):
    def get_browser(self):
        metadata = self.context.get_registered_star("astrbot_plugin_browser")
        if (
            metadata is None
            or not metadata.activated
            or metadata.star_cls is None
        ):
            raise RuntimeError("请先启用 astrbot_plugin_browser")

        browser = metadata.star_cls.service
        if not browser.ready:
            raise RuntimeError("共享渲染服务未启用或尚未就绪")
        return browser
```

浏览器服务的生命周期由本插件管理。其他插件通过 `metadata.star_cls.service` 获得受限接口，该接口只提供 `ready`、`render_html()`、`render_pdf()` 和 `session()`。示例中的 `browser` 是此服务接口，不是 Playwright 的 `Browser`；公开接口不提供 `initialize()`、`close()`、底层浏览器操作或 Playwright 运行时。

底层 `_operation()` 仅供本插件内部使用，不属于插件间接入接口，不提供 `operation()` 别名。页面和元素也通过白名单包装，仅允许当前渲染任务的操作。这是公开 API 对误用和过度授权的限制，不是针对同进程恶意 Python 代码的安全沙箱；其他插件不要依赖或通过反射访问内部对象。

共享渲染启用且开启空闲关闭后，`service.ready` 在实例休眠时仍表示服务可接受请求，调用方无需另行启动实例。`render_html()`、`render_pdf()` 和 `session()` 自动唤醒实例；PNG/PDF 渲染的整体超时包含唤醒耗时，超时设置很短的调用需要为浏览器启动留出时间。

### 接口一：`render_html()`

把完整 HTML 渲染为 PNG 字节：

```python
browser = self.get_browser()

png = await browser.render_html(
    """
    <!doctype html>
    <html lang="zh-CN">
      <head>
        <meta charset="utf-8">
        <style>
          body { margin: 0; padding: 32px; font-size: 24px; }
          .card { padding: 24px; border: 1px solid #ddd; }
        </style>
      </head>
      <body><main class="card">本地 HTML 截图</main></body>
    </html>
    """,
    viewport={"width": 900, "height": 720},
    selector=".card",
)
```

参数：

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `html` | 必填 | 完整 HTML 字符串，最大 48 MiB |
| `viewport` | `1280x720` | CSS 视口，宽高均为 1～8192；面积最多约 1678 万像素 |
| `selector` | `None` | 指定元素截图；元素不存在或不可见时抛出 `BrowserServiceError` |
| `full_page` | `True` | 没有 `selector` 时是否截取完整页面 |
| `javascript_enabled` | `False` | 是否为本次页面启用 JavaScript |
| `timeout` | `30` | 本次任务超时时间，范围 0.1～300 秒 |
| `max_pixels` | `32000000` | 整页或目标元素的最大截图面积；传 `None` 可关闭该项检查 |

返回值是 PNG `bytes`：

```python
from astrbot.api.message_components import Image

image = Image.fromBytes(png)
```

指定 `selector` 时只截取目标元素；不指定时，`full_page=True` 会截取整个页面，`full_page=False` 只截取当前视口。

### 接口二：`render_pdf()`

把完整 HTML 渲染为 PDF 字节：

```python
browser = self.get_browser()

pdf = await browser.render_pdf(
    "<html><body><h1>报告</h1><p>本地 PDF 内容</p></body></html>",
    format="A4",
    print_background=True,
    margin={
        "top": "10mm",
        "right": "10mm",
        "bottom": "10mm",
        "left": "10mm",
    },
)
```

参数：

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `html` | 必填 | 完整 HTML 字符串，最大 48 MiB |
| `format` | `A4` | Chromium 纸张格式，例如 `A4`、`Letter`、`Legal` |
| `landscape` | `False` | 是否横向排版 |
| `print_background` | `True` | 是否打印 CSS 背景 |
| `prefer_css_page_size` | `True` | 是否优先使用 CSS `@page` 尺寸 |
| `margin` | `None` | 页边距字典，值使用 CSS 单位，例如 `8mm`、`1cm` |
| `viewport` | `1280x720` | 页面布局使用的 CSS 视口 |
| `javascript_enabled` | `False` | 是否为本次页面启用 JavaScript |
| `timeout` | `30` | 本次任务超时时间，范围 0.1～300 秒 |

返回值是 PDF `bytes`。服务不会替调用方写入文件：

```python
from pathlib import Path

Path("report.pdf").write_bytes(pdf)
```

### 接口三：`session()`

需要自行测量 DOM、分页或控制截图细节时，使用页面会话接口。返回对象是 `RenderPage`，其 `locator()` 返回 `RenderLocator`，二者均不是原生 Playwright 对象：

```python
browser = self.get_browser()

async with browser.session(
    viewport={"width": 1200, "height": 2100},
    javascript_enabled=False,
    device_scale_factor=1,
    timeout=30,
) as page:
    await page.set_content(
        "<html><body><main id='content'>报告内容</main></body></html>",
        wait_until="load",
    )
    await page.evaluate("document.fonts.ready")

    height = await page.locator("#content").evaluate(
        "element => element.scrollHeight"
    )
    png = await page.locator("#content").screenshot(
        type="png",
        animations="disabled",
    )
```

`session()` 参数：

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `viewport` | `1280x720` | CSS 视口尺寸 |
| `javascript_enabled` | `False` | 仅影响当前会话 |
| `device_scale_factor` | `1` | 设备像素比，范围 0.5～3 |
| `timeout` | `30` | Playwright 默认操作超时时间，范围 0.1～300 秒；不是整个会话的时限 |

页面和元素通过明确的白名单提供以下能力；没有原生对象的通用转发。

#### `RenderPage`

| 方法或属性 | 参数和返回值 |
|---|---|
| `url` / `viewport_size` | 当前网址字符串 / 视口字典副本；都是纯数据 |
| `set_content(html, *, wait_until="load", timeout=None)` | HTML 最大 48 MiB；加载状态为 `commit`、`domcontentloaded`、`load`、`networkidle` |
| `content()` / `title()` | 返回 HTML / 标题字符串 |
| `evaluate(expression, arg=None)` | 在当前页面执行脚本，结果按值返回，不创建句柄 |
| `locator(selector, *, has_text=None, has_not_text=None, has=None, has_not=None)` | 返回包装后的 `RenderLocator`；文本筛选支持字符串或编译后的正则表达式 |
| `set_viewport_size(viewport_size)` | 调整 CSS 视口；宽高及面积限制与创建会话一致，同时检查设备像素比后的面积 |
| `emulate_media(*, media=None, color_scheme=None, reduced_motion=None, forced_colors=None, contrast=None)` | 控制打印/屏幕、配色、动画、强制颜色和对比度偏好，取值沿用 Playwright |
| `wait_for_load_state(state="load", *, timeout=None)` | 等待 `domcontentloaded`、`load` 或 `networkidle` |
| `screenshot(...)` | 返回 PNG / JPEG 字节，参数见下表 |
| `pdf(...)` | 打印当前页面并返回 PDF 字节，参数见下文 |

#### `RenderLocator`

| 方法或属性 | 参数和返回值 |
|---|---|
| `page` | 返回所属的 **RenderPage 包装**，不返回原生 Page |
| `first` / `last` / `nth(index)` | 返回第一个 / 最后一个 / 指定下标的包装 Locator |
| `all()` / `count()` | 返回包装 Locator 列表 / 匹配数量；`all()` 不等待元素出现 |
| `locator(selector_or_locator, *, has_text=None, has_not_text=None, has=None, has_not=None)` | 嵌套定位；第一个参数可用选择器或同页包装 Locator，返回值继续包装 |
| `filter(*, has_text=None, has_not_text=None, has=None, has_not=None, visible=None)` | 过滤匹配结果，返回包装 Locator |
| `inner_text(*, timeout=None)` / `text_content(*, timeout=None)` / `inner_html(*, timeout=None)` | 返回文字 / 原始文本（可能为 `None`）/ 元素内部 HTML |
| `get_attribute(name, *, timeout=None)` | 返回属性字符串或 `None` |
| `is_visible(*, timeout=None)` / `is_hidden(*, timeout=None)` | 返回可见 / 隐藏状态；沿用 Playwright 立即检查语义，`timeout` 不产生等待 |
| `wait_for(*, state="visible", timeout=None)` | 等待 `attached`、`detached`、`visible` 或 `hidden` |
| `scroll_into_view_if_needed(*, timeout=None)` | 将元素滚动到视口内 |
| `evaluate(expression, arg=None, *, timeout=None)` | 脚本接收元素和数据参数，结果按值返回；`timeout` 限制定位元素的等待 |
| `evaluate_all(expression, arg=None)` | 脚本接收匹配元素数组及数据参数，结果按值返回 |
| `bounding_box(*, timeout=None)` | 返回 `x`、`y`、`width`、`height` 字典，或 `None` |
| `screenshot(...)` | 返回元素截图字节，参数见下表 |

`has`、`has_not`、嵌套定位和截图 `mask` 中传入的 Locator 必须属于**同一个 RenderPage**。原生 Playwright Locator 和其他渲染会话的包装 Locator 都会被拒绝，不会以此接触 BrowserUse 会话。

#### 截图参数

以下参数同时适用于 `page.screenshot()` 和 `locator.screenshot()`，其中 `full_page` 和 `clip` 仅适用于页面：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `type` | `"png"` | `png` / `jpeg`；始终返回 `bytes` |
| `animations` | `"allow"` | `allow` / `disabled` |
| `timeout` | `None` | 单次操作超时，**毫秒**；`None` 使用会话默认值，`0` 关闭这次操作的超时 |
| `quality` | `None` | JPEG 质量 0～100；PNG 不支持 |
| `omit_background` | `None` | 隐藏默认白色背景，PNG 可保留透明度 |
| `caret` | `None` | `hide` / `initial`；省略时沿用 Playwright 默认值 |
| `scale` | `None` | `css` / `device`；省略时沿用 Playwright 默认值 |
| `mask` | `None` | 同页 RenderLocator 列表或元组，用于遮盖选中元素 |
| `mask_color` | `None` | 遮罩颜色，例如 `#000000` |
| `style` | `None` | 仅在截图时应用的 CSS 字符串 |
| `full_page` | `False` | 仅页面支持；是否截取整页 |
| `clip` | `None` | 仅页面支持；包含 `x`、`y`、`width`、`height` 的 CSS 像素区域 |

截图不接受 `path`。如果需要文件，调用方保存返回的字节：

```python
import asyncio
from pathlib import Path

async with browser.session(timeout=30) as page:
    await page.set_content("<main class='board'>计划看板</main>", timeout=15_000)
    png = await page.locator(".board").screenshot(
        type="png", animations="disabled", timeout=15_000
    )

await asyncio.to_thread(Path("board.png").write_bytes, png)
```

#### 当前页面 PDF

`page.pdf()` 支持以下关键字参数，默认均为 `None`，沿用 Playwright 的打印默认行为：

- 排版：`scale`、`landscape`、`format`、`width`、`height`、`prefer_css_page_size`、`margin`、`page_ranges`。
- 内容：`print_background`、`display_header_footer`、`header_template`、`footer_template`。
- 文档结构：`outline`、`tagged`。

`width`、`height` 和边距可使用 CSS 单位字符串或数值；数值单位为像素。`pdf()` 始终返回 `bytes`，不接受 `path` 或 `timeout`。如需 HTML 加载、字体等待及整个导出的超时保护，可直接使用上层 `render_pdf()`。

#### 脚本参数、超时和退出

`evaluate()` / `evaluate_all()` 的脚本必须是非空 JavaScript 字符串。`arg` 可包含 `None`、布尔值、数字（含 `NaN` / `Infinity`）、字符串、`datetime.datetime`、列表、元组和字符串键字典，允许列表/字典的循环引用；拒绝原生 Playwright 对象以及任意自定义 Python 对象。脚本结果由 Playwright 按值传回，不返回 Frame、JSHandle 或 ElementHandle。

`session(timeout=30)` 的单位是**秒**，范围 0.1～300，设置默认操作时限。页面和元素方法上的 `timeout` 单位是**毫秒**，可为非负有限数或 `None`，`0` 表示关闭该次操作超时。`Page.evaluate()`、`evaluate_all()` 和 `pdf()` 原生没有 `timeout` 参数；Locator 的 `evaluate(timeout=...)` 仅限制定位元素，不限制脚本执行。调用方需要为整段自定义操作设置总体超时（例如 `asyncio.wait_for()`）。

截图传入非零 `timeout` 时，包装层也限制整次截图的等待时间，包含元素定位；不会为此修改页面的默认超时或影响同页其他调用。

不提供 `page.context`、Browser、Frame、句柄、接收原生对象的事件回调、请求/路由管理、文件上传或浏览器生命周期控制。没有列出的属性或方法抛出 `AttributeError`，未知关键字参数抛出 `TypeError`，不会回退到原生对象。已有接入方若使用 `path`，应改为自行保存截图或 PDF 字节；若依赖原生类型检查或未公开接口，也需要按此契约调整。

会话退出时，页面和 BrowserContext 自动关闭，已有的页面及所有派生 Locator 包装失效，继续使用会抛出 `BrowserServiceError`。正常退出、异常和取消都会执行清理。

<a id="boundaries"></a>

## 🛡️ 边界与错误

- 每个渲染任务使用独立、临时的 Context，不载入 BrowserUse 的登录快照，不共享它的 Cookie、存储和页面。
- 公开页面及 Locator 只允许当前渲染任务的操作，返回关联页面时仍是包装对象；不暴露原生 Browser/Context/句柄或文件路径能力。
- 页面请求被中止，外部 CSS、图片、字体和脚本不会加载，本机文件也不能通过页面请求读取。启用 JavaScript 不改变请求拦截规则。
- HTML 输入最大 48 MiB。视口宽高为 1～8192，面积及乘设备像素比后的面积最多 16777216 像素。
- `render_html()` 默认限制截图面积为 3200 万像素；使用 `session()` 时由调用方控制整页/元素截图面积。
- `render_html()` 和 `render_pdf()` 有整体超时。`session()` 只设置默认操作超时，脚本执行和整段会话的时限由调用方管理。

这是公开 API 对误用和过度授权的限制，**不是同进程恶意 Python 代码的安全沙箱**。同一 AstrBot 进程中的插件仍拥有 Python 反射及宿主进程本身的权限；不要将私有属性视为凭证隔离的安全边界。BrowserUse 工具权限与登录文件管理见[BrowserUse](./BrowserUse.md#permissions)。

共享渲染已关闭、服务不可用、参数验证、Playwright 操作失败和已结束会话的访问抛出 `BrowserServiceError`；不支持的属性和关键字参数分别抛出 `AttributeError`、`TypeError`。底层 Playwright 异常保留在 `__cause__` 中，调用方可记录完整异常定位超时或布局错误。

## 🧯 故障排查

### 浏览器安装或启动失败

启用任一功能后，插件找不到浏览器时会自动安装 Chromium。自动安装失败时，检查网络、写入权限和浏览器系统依赖，并在运行 AstrBot 的同一 Python 环境中执行：

```bash
python -m playwright install chromium
```

Linux 缺少系统依赖时使用 `python -m playwright install --with-deps chromium`。如果设置了 `browser.browser_executable`，检查路径是否绝对、文件是否存在、是否含多余引号；指定路径启动失败时不会自动切换程序。

### 离线渲染缺少外部资源

渲染接口会中止页面的外部请求，外部 CSS、图片、字体和脚本不会加载。请将资源内联，或由调用方先取得资源后生成完整 HTML；即使为当前任务启用 JavaScript，也不会改变请求拦截规则。

Agent 联网页面使用独立 Context，网页资源照常请求，不受离线渲染约定影响。

### 任务排队、超时或实例迟迟没有关闭

BrowserUse 与渲染共用执行名额，满额后等待 `browser.queue_timeout` 秒。PNG/PDF 渲染与 BrowserUse 另有整体超时；休眠后的首次请求还包含唤醒等待。调大并发前应考虑每个页面额外占用的内存。

实例空闲关闭要求没有保留的无头 Context 和运行中、排队中的无头任务。Agent 会话仍在保留时，先等待会话回收，再等待实例空闲超时；后台检查还可能延后约 30 秒。

### 接入后出现参数或属性错误

`service` 是本插件主动公开的 `BrowserServiceAPI`，`session()` 返回 `RenderPage`，不是原生 Playwright Page。请对照[页面接口](#integration)检查能力范围。截图的 `timeout` 已提供，单位为毫秒；`path` 仍不支持，改为保存返回的字节。不要通过内部对象或通用属性转发规避公开接口限制。

BrowserUse 的工具权限、截图观察和登录恢复问题见[BrowserUse 故障排查](./BrowserUse.md#faq)。

## 🛠️ 开发验证

在已安装 AstrBot 依赖的同一 Python 环境中运行：

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m ruff check .
python -m ruff format --check .
```

`tests/test_render_api.py` 使用真实 Chromium 验证公开页面及 Locator 不暴露上层浏览器对象，拒绝文件路径、原生句柄及跨会话 Locator；也验证恢复的操作超时、截图参数、包装 Locator 链、按值脚本参数、页面 PDF、请求拦截和正常/异常/取消后的失效与清理。存在可导入的相邻 `astrbot_plugin_markdown_render` 时，还会原样调用其渲染器验证普通 Markdown、公式和 Mermaid；缺少该插件时仅跳过相应集成项。

`tests/test_service.py` 的额外 PNG/PDF 冒烟测试通过 `ASTRBOT_BROWSER_EXECUTABLE` 指定浏览器路径启用。空闲关闭另验证渲染唤醒、并发启动、排队及运行任务保护、保留 Context、登录恢复、有头实例隔离和插件停止时的清理。BrowserUse 专项覆盖见[BrowserUse 开发验证](./BrowserUse.md#development)。文档调整可单独检查本地链接、锚点、工具清单与配置默认值。
